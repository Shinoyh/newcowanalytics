# NewCowAnalytics 🐮📊

NewCowAnalytics는 유튜브 채널과 인스타그램 계정의 성장 추세, 사용자 반응(Engagement), 그리고 AI를 활용한 훅(Hook) 분석 기능을 제공하는 종합 소셜 미디어 분석 대시보드입니다.

## 📥 0단계: 코드 다운로드 하기 (Download Code)

가장 먼저 이 프로그램의 코드를 내 컴퓨터로 가져와야 합니다.
1. 지금 보고 계신 깃허브 화면 우측 상단의 초록색 **[ <> Code ]** 버튼을 클릭합니다.
2. 메뉴 맨 아래에 있는 **[Download ZIP]**을 클릭하여 압축 파일을 다운로드합니다.
3. 다운로드 받은 `newcowanalytics-master.zip` 파일의 압축을 원하시는 폴더(예: `바탕화면` 또는 `문서`)에 풀어주세요.

## 🛠️ 1단계: 필수 설치 항목 (Prerequisites)

개발 지식이 없는 분들도 쉽게 따라 하실 수 있도록 기초부터 설명합니다. 아래 프로그램들이 PC에 설치되어 있어야 합니다.

1. **Java 17 (JDK)**: 백엔드 서버를 켜기 위해 필요합니다. [오라클 홈페이지](https://www.oracle.com/java/technologies/javase/jdk17-archive-downloads.html)에서 설치할 수 있습니다.
2. **Node.js**: 프론트엔드 화면을 띄우기 위해 필요합니다. [Node.js 공식 홈페이지](https://nodejs.org/)에서 안정적(LTS) 버전을 다운받아 설치해 주세요. (설치 시 무조건 'Next'만 누르시면 됩니다.)
3. **Python 3.10 이상**: AI 영상 분석을 위해 필요합니다. [Python 홈페이지](https://www.python.org/downloads/)에서 설치해 주세요. **(중요: 설치 창 맨 아래에 `Add Python to PATH` 체크박스를 무조건 체크하셔야 합니다!)**

## 🔑 2단계: 필수 파일 및 API 키 셋팅

### 1. 외부 프로그램 수동 다운로드 (.exe)
용량 문제로 GitHub에 포함되지 않은 2개의 파일을 직접 다운로드하여 `ai/` 폴더 안에 넣어주셔야 합니다.
- [yt-dlp.exe 다운로드](https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp.exe) (영상 추출용)
- [ffmpeg.exe 다운로드](https://github.com/BtbN/FFmpeg-Builds/releases) (오디오 인코딩용 - 압축을 풀고 `bin` 폴더 안의 `ffmpeg.exe`만 복사하세요)
- 다운받은 두 개의 파일을 프로젝트의 `ai` 폴더 안으로 이동시켜 주세요.

### 2. 구글 및 유튜브 API 키 발급 및 입력
이 프로그램이 유튜브 데이터를 긁어오고 구글 AI(Gemini)를 사용하려면 '열쇠(API Key)'가 필요합니다.
- 유튜브 키 발급: [Google Cloud Console](https://console.cloud.google.com/)에서 YouTube Data API v3 키를 발급받습니다.
- 제미나이 키 발급: [Google AI Studio](https://aistudio.google.com/app/apikey)에서 Gemini API 키를 발급받습니다.

발급받은 키를 코드에 입력해야 합니다!
- 프로젝트 폴더 안에서 `backend/src/main/resources/application.yml` 파일을 메모장으로 엽니다.
- 아래 부분을 찾아 `YOUR_YOUTUBE_API_KEY`와 `YOUR_GEMINI_API_KEY` 글자를 지우고, 발급받은 본인의 키를 붙여넣기 한 뒤 저장하세요.
```yaml
app:
  social:
    youtube:
      api-key: "여기에_유튜브_키를_넣으세요"
  ai:
    gemini:
      api-key: "여기에_제미나이_키를_넣으세요"
```

## 🏃‍♂️ 3단계: 프로젝트 실행하기 (How to Run)

모든 준비가 끝났습니다! 이제 서버를 켜고 접속해 봅시다. 이 프로그램은 **백엔드(데이터)**와 **프론트엔드(화면)** 두 개의 심장을 가지고 있어서 두 개를 모두 켜주셔야 합니다.

### Step 1. 터미널(명령 프롬프트) 창 2개 열기
윈도우 시작 메뉴에서 **'cmd'**(명령 프롬프트)를 검색해서 **두 개**를 띄워주세요.
그리고 두 창 모두 `cd` 명령어를 이용해 코드가 다운로드된 폴더로 이동합니다. (예: `cd C:\Users\내이름\Downloads\NewCowAnalytics`)

### Step 2. 백엔드 서버 켜기
첫 번째 까만 창(cmd)에 아래 두 줄을 차례대로 복사해서 붙여넣고 엔터를 치세요.
```cmd
cd backend
gradlew.bat bootRun
```
*(Mac 유저는 `./gradlew bootRun` 입니다.)*
막 글자들이 올라가다가 멈추고 `Tomcat started on port 8080`이라는 문구가 뜨면 백엔드가 성공적으로 켜진 것입니다. **(이 창은 절대 끄지 마시고 그대로 두세요!)**

### Step 3. 프론트엔드 서버 켜기
두 번째 까만 창(cmd)에 아래 세 줄을 차례대로 복사해서 붙여넣고 엔터를 치세요.
```cmd
cd frontend
npm install
npm run dev
```
글자들이 주르륵 올라간 뒤 `➜  Local:   http://localhost:5173/` 이라는 문구가 나타나면 화면 서버도 성공적으로 켜진 것입니다. **(이 창도 그대로 두세요!)**

### Step 4. 웹 페이지 접속하기
이제 즐겨 쓰시는 인터넷 브라우저(크롬, 엣지 등)를 열고 주소창에 아래 링크를 입력하세요.
👉 **[http://localhost:5173](http://localhost:5173)**

짜잔! 화면에 NewCowAnalytics 대시보드가 나타났다면 성공입니다! 상단 검색창에 `@mrbeast` 등 유튜브 채널을 검색하여 마음껏 분석을 시작하세요.

> **끄고 싶을 때는?** 
> 열어두었던 두 개의 까만 창(터미널)에서 각각 **`Ctrl + C`** 키를 연속으로 누르시면 서버가 안전하게 종료됩니다.

## 🚀 주요 기능 (Features)

웹 페이지에 접속하면 다음과 같은 작업들을 수행할 수 있습니다.

### 1. 채널/계정 검색 및 기본 데이터 시각화
- 홈 화면 상단 검색바를 통해 유튜브 채널명(예: `@mrbeast`)을 검색할 수 있습니다.
- 채널의 최근 200개 영상 데이터를 불러와 조회수, 좋아요, 댓글 등의 인게이지먼트를 차트로 한눈에 보여줍니다.
- **차트 탐색 편의성**: 그래프의 아주 작은 점을 정확히 누르기 위해 애쓸 필요 없이, 마우스를 올렸을 때 나타나는 '세로 기준선 영역' 위아래 빈 공간 어디든 클릭하면 해당 시점의 상세 영상 목록이 즉시 나타납니다.
- 최근 50개 포스트와 과거 포스트의 인게이지먼트 **중앙값(Median)**을 비교하여 정확한 성장률을 계산합니다.
- **실시간 데이터 갱신**: 홈 화면 우상단의 `🔄 데이터 갱신` 버튼을 누르면 기존 DB 캐싱 결과를 무시하고 소셜 플랫폼의 가장 최신 실시간 데이터를 다시 불러와 분석할 수 있습니다.

### 2. 최상위 훅(Top Hooks) 분석
- 채널 내 조회수 최상위 영상 3개를 나란히 띄워줍니다.
- 마우스를 올리면(Hover) 영상이 자동으로 재생되어 시청자를 사로잡은 초반 3초 훅(Hook)을 비교 분석할 수 있습니다.
- **3줄 요약 미리보기**: AI 심층 분석이 완료된 영상은 썸네일 하단에 **✨ AI 3줄 요약**이 직관적인 카드 형태로 즉시 표시되어, 굳이 창을 열지 않고도 해당 영상의 핵심 전략을 한눈에 파악할 수 있습니다.

### 3. AI 총평 분석 (Channel Trend Analysis)
- `✨ AI 채널 총평 분석` 버튼을 누르면 Gemini AI가 채널의 전반적인 성장세(상승세/하락세/정체기)와 그 원인, 주요 흥행 요인, 전략적 조언을 정리해 줍니다.

### 4. 영상 일괄 및 개별 AI 심층 분석 (Video Specific Analysis)
- 특정 영상을 클릭하거나, 영상들의 **체크박스를 다중 선택**하여 백그라운드 **일괄 족집게 분석(Batch Analysis)**을 큐(Queue)에 예약할 수 있습니다.
- **안정적인 큐 처리**: 여러 영상을 한꺼번에 큐에 넣어도 서버 단에서 2초씩 대기하며 순차적으로 API를 호출하므로 구글 서버의 트래픽 제한(Rate Limit 429 에러)을 완벽하게 방지합니다.
- 우측 하단 팝업(Toast)을 통해 실시간 분석 진행 상황을 추적할 수 있으며, **최소화(-)** 버튼을 통해 콤팩트하게 숨기거나 X 버튼을 눌러 화면에서 깔끔하게 정리할 수 있습니다.
- **💡 AI 분석 결과 모아보기 (아카이브)**: 프로필 하단의 전용 버튼을 통해 현재 채널에서 성공적으로 AI 분석을 마친 영상들만 따로 모아 리스트 형태로 한눈에 볼 수 있으며, 클릭 한 번으로 과거 분석 결과를 언제든 다시 열람할 수 있습니다.
- **친절한 에러 방어막 구축**: API 할당량 초과, 연령 제한 등 구글 AI나 유튜브 측에서 에러가 발생하면 무너지지 않고 사용자 친화적인 한국어 에러 안내(Toast 클릭 유도)를 통해 직관적으로 원인을 파악하고, 문제가 된 영상을 버튼 하나로 '강제 재분석(Force Refresh)' 할 수 있습니다.
- **안정적인 UI/UX 렌더링**: 영상 선택 체크박스 다중 클릭 시 스크롤이 최상단으로 요동치던 현상을 최적화하여 쾌적한 사용성을 보장합니다.
- `✨ 상세 분석 결과 열기` 버튼을 클릭하면, 해당 영상의 숏폼/롱폼 여부에 맞춰 오디오와 영상을 추출한 뒤 Gemini AI가 분석한 **시각적/청각적/서사적 후킹 요소와 감정 자극 포인트**를 심층 모달 창에서 꼼꼼하게 확인할 수 있습니다.

## ✨ 최근 추가된 편의 기능 (Recent Updates)

- **AI 분석 진행 상태창 숨기기**: 분석이 오래 걸릴 때 진행 상태(Toast) 창을 최소화(-)하고 닫을(X) 수 있습니다.

- **유튜브 검색 고도화**: 동명이인(가짜 깡통 채널)이 존재할 때 잘못된 채널이 분석되는 현상을 막기 위해, 고유 식별 ID를 사용하도록 검색 로직이 100% 완벽하게 패치되었습니다.

## 🤖 AI 모델 변경 가이드 (How to change the AI Model)

기본적으로 `gemini-3.5-flash` 모델을 사용하도록 하드코딩되어 있습니다. 만약 더 고성능 모델(예: `gemini-1.5-pro` 등)로 변경하고 싶다면 다음 과정을 따르세요.

1. `ai/ai_analyzer.py` 파일을 에디터로 엽니다.
2. `client.models.generate_content` 함수가 호출되는 라인을 찾습니다. (파일 내 2곳 존재)
   - `analyze_video` 함수 내부
   - `analyze_channel` 함수 내부
3. 해당 라인의 `model='gemini-3.5-flash'` 부분을 원하는 모델 이름으로 변경합니다.
   ```python
   # 변경 전
   response = client.models.generate_content(model='gemini-3.5-flash', ...)
   
   # 변경 후
   response = client.models.generate_content(model='gemini-1.5-pro', ...)
   ```
4. 파일을 저장한 후 서버에서 AI 분석을 다시 실행하면 즉시 변경된 모델이 적용됩니다. (서버 재시작 불필요)
